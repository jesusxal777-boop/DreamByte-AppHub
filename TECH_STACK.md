# DreamByte AppHub — Tech Stack

## Chosen stack

| Layer | Choice | Version / notes |
|---|---|---|
| Language | Swift | 6.4 (Linux toolchain for core; Swift 6 language mode) |
| UI | SwiftUI | iOS/iPadOS 26 APIs, deployment target 18.0 with availability fallbacks |
| Build | SwiftPM | Two packages: `Core` (cross-platform), `App` (iOS) |
| App packaging | xtool (Linux) / Xcode 27.1 (macOS) | xtool requires Swift 6.4 + Darwin SDK from Xcode 27.1 |
| Networking | URLSession | `FoundationNetworking` on Linux; native on iOS |
| Compression | system zlib via C shim | No third-party dependency; available on iOS and Linux |
| Plists | `PropertyListSerialization` | XML + binary |
| Signing | Security.framework (`SecPKCS12Import`, `CMSDecoder`) | iOS only; isolated behind adapters |
| Hashing | Pure Swift SHA-256 + CRC-32 | Deterministic and testable on Linux |
| Persistence | Files + `UserDefaults` + Keychain | No database needed for v1 |
| Testing | XCTest | Fixtures generated as real ZIP/IPA files |
| Localization | `.strings` (es/en/fr/pt) + runtime `Localizer` | No external library |
| Branding | `BrandTheme` + asset catalog + `branding.json` | Placeholder-only until DreamByte supplies assets |

## Explicitly rejected

| Option | Why not |
|---|---|
| Flutter / React Native | Brief requires native Swift/SwiftUI and Liquid Glass fidelity |
| Third-party ZIP library (ZIPFoundation) | Adds a dependency for metadata-only needs; custom reader enforces stricter limits |
| SQLite/Core Data | Overkill for a handful of IPA/repo records; file-backed models are simpler and portable |
| SwiftGen / R.swift | Extra toolchain step; typed keys are generated by a small test-enforced convention |
| Bundling StikJIT now | AGPL obligations, Xcode-only extension, untestable here; planned as opt-in |
| Jailbreak dependencies | Not required and would exclude most users |
| Private installation APIs in v1 | Cannot be validated here and would make the app non-distributable; deferred behind an explicit bridge |

## Deployment targets

- iOS/iPadOS **18.0 minimum** (broad device support, `@Observable`, modern navigation).
- iOS **26** feature set enabled at runtime: Liquid Glass, new toolbar/tab appearances.
- iOS 27 readiness: no deprecated APIs; availability checks isolate 26-only modifiers.

## Build commands

```bash
# Core: works on this Linux host
cd Core
swift build
swift test

# App: requires macOS + Xcode 27.1 (or xtool with Darwin SDK)
cd App
swift build --sdk darwin   # xtool toolchain
# or open App/Package.swift in Xcode 27.1 and run on a device
```

## Non-goals for v1

- In-app installation without an external signing/installation path.
- App Store distribution of system-wide app enumeration.
- Universal JIT activation.
- Paid services, accounts, telemetry, or subscriptions.
